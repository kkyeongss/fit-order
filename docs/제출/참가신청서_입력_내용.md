# 참가신청서·서약서·동의서 작성 안내

안내문(`공공데이터_활용_사례_공모전(안내문).hwp`)의 붙임1(참가 신청서·서약서), 붙임1-1(개인정보 동의서)은 **본인 정보와 서명이 필요해서 직접 작성**해야 합니다. 아래는 신청서에 붙여 넣을 수 있는 내용과 확인 목록입니다.

| 참가분야 | 활용 사례 |
| 활용사례 제목 | 핏오더(FitOrder) — 공공 근무복 주문 데이터 기반 사이즈별 발주 추천 및 ESG 효과 분석 서비스 |
| 활용데이터 | 한국체육산업개발주식회사_근무복 주문현황, 한국체육산업개발주식회사_근무복 주문현황정보, 한국체육산업개발주식회사_정원현황, 조달청_나라장터쇼핑몰 품목정보 서비스, 한국환경산업기술원_녹색제품 정보조회 서비스 GW |

**활용사례 기획 개요** (칸이 작으면 앞의 두세 문장만 쓰세요)

> 근무복 주문 CSV 2종(2017.11~2026.8)과 정원현황으로 품목·사이즈별 발주 수량을 계산해 주는 웹 서비스입니다. 사이즈 구성이 해마다 바뀌어(셔츠 105~120 비중 2020년 29% → 2025년 58%) 이전 비율로 주문하면 16~18%가 어긋나는 점에 착안해, 직전 2년 평균·격년 품목 규칙·최근 3년 사이즈 비율(3:2:1)·안전재고로 추천 수량과 산정 근거를 제시하고 엑셀 발주표를 제공합니다. 조달청 계약가격으로 금액을, 환경표지 구분으로 녹색구매 비용 차이를 보여주며, 절감 효과를 절감액·탄소 감축량(ESG 지표)으로 환산합니다. 시연: https://fitorder.duckdns.org (user / user1234)

## 2. 직접 채워야 하는 항목 (제가 알 수 없는 개인 정보)

- [ ] 참가구분: 개인 / 팀 (팀이면 팀장 정보 + 팀원 최대 4명, 팀명)
- [ ] 성명(대표자), 생년월일, 휴대전화번호, 이메일, 주소, 소속(기업)
- [ ] 참가 서약서: 날짜, 신청인 이름과 서명(인)
- [ ] 개인정보 수집·이용 동의서: 날짜, 이름, 서명, 동의 여부(□ 동의 / □ 거부) — 거부하면 참가가 제한됩니다

## 3. 서약서에서 본인이 확인할 내용

- 2번: 신청서·기획서에 적은 내용이 사실임을 확인합니다. 기획서의 수치는 2026-11-28 시연 서버 값이고, 절감 효과(개선률 50%)와 일부 단가(점퍼·조끼·패딩조끼 추정 53,000원)는 **가정값**이라고 기획서에 밝혀 두었습니다.
- 4번: 같은 또는 비슷한 작품으로 다른 대회에서 수상한 적이 없어야 합니다.
- 6번: **수상하면 소스 제공과 2028년까지 서비스 운영 협조**에 동의하는 것입니다. 소스는 이미 공개 저장소에 있고, 운영 방법은 기획서 5-2에 적었습니다.
